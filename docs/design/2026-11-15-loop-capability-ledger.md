- **Related**: [Unified agent loop](2026-10-23-unified-agent-loop.md) (the ladder and the rollout rules), [Event-bus agent loop](2026-11-11-event-bus-agent-loop.md), [Streaming tool dispatch](2026-11-11-streaming-tool-dispatch.md), [Hosted Harness evaluation](2026-11-14-hosted-harness-loop-evaluation.md).

## How to read it

Each row is one behavior of the 1.0 loop, the code in `event-bus/`, `tool-executor/` and `core/query-*`, mapped to main:

- `have`: main does it with the same effect;
- `differs`: main does it with an observable difference, given in the note;
- `missing`: main has no equivalent;
- `not porting`: the behavior belongs to streaming tool dispatch, or to 1.0's session, provider, protocol, compression or reporting modules, which #17045 does not port.

  1.0 paths are under `packages/core/src/` at the tag. Main paths are under `packages/core/src/`, except those starting with `cli/`, which are under `packages/cli/src/`. Main keeps continuation and recovery inside `LlmClient` and `LlmChat` on purpose (#17045, "Not planned"), so a row is `differs` only for a difference a user or a host can observe, not for where the code lives.

Rows found after 2026-11-21 go to the follow-up issue.

### Continuation and recovery (the `differs` rows of "Not planned")

Continuation and recovery stay in `LlmClient` and `LlmChat`. The differences in C4, C7, C9, C12, C18, C21, C22, C26, C27 and C29 are accepted as main's behavior and listed here so a surface's release notes can cite them. Three are hook contract differences that a hook author can rely on, and go to the follow-up issue as fixes:

- C10: a Stop hook's `continue: false` should end the turn instead of continuing the model;
- C14 and T11: a PostToolUse or PreToolUse `stop` should end the turn instead of failing only the call;
- C28: headless should fire StopFailure when a request fails, as the TUIs and ACP do.
